# Car Service & Mechanic Hub - Frontend

React 19 + Vite frontend application for Car Service & Mechanic Hub.

## Scripts
- `npm run dev`: Start local Vite development server
- `npm run build`: Build production bundle (`dist`)
- `npm run preview`: Preview production build locally

## Environment Variables
- `VITE_API_URL`: Base URL of the backend API (e.g., `https://car-service-backend.onrender.com` in production or `http://localhost:5001/api` in development)
